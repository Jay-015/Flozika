Before uploading your file, please make sure it meets the supported file type and size requirements.

Maximum File Size

Flozika supports the following maximum file sizes:

JPG / JPEG Image File
10 MB
PNG Image File
10 MB
PDF Document File
25 MB
DOC / DOCX Word Document
20 MB

Important Notes

  • Please upload files within the specified size limit.
  • Files exceeding the maximum allowed size cannot be processed.
  • Supported file types may depend on the selected conversion.
  • For better performance, use reasonably sized files.
  • Uploaded files are processed temporarily for conversion.
